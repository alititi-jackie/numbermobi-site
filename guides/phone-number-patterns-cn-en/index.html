顺子号、豹子号、回文号的英文怎么说？美国手机号码类型中英对照

在美国买手机靓号，英文世界有一套自己的说法：三连号叫 triple，顺子号叫 sequential，豹子号叫 repeater。这张对照表把华人常说的号码类型和对应的英文术语一一对应，并配上例子，帮你和英文卖家、运营商客服无障碍沟通，也帮你看懂英文二级市场的号码 listing。

为什么需要这张对照表

英文里并没有"靓号"这个词。最接近的说法是 vanity number（狭义指拼词号）、memorable number（好记的号码）或 pattern number（有规律的号码），华人说的三连号、四连号、豹子号，在英文里都属于 pattern numbers。当你跟运营商客服沟通、看 eBay 上的号码 listing，或者跟美国本地卖家打交道时，直接用英文术语比连比划带翻译高效得多。这张表就是为此准备的：左边是你熟悉的中文叫法，右边是英文世界通用的术语。

几个容易混淆的说法

第一，豹子号千万不要直译成 leopard，英文里没人这么说，正确说法是 repeater 或 repeating digits，卖家一听就懂。第二，顺子在扑克牌里叫 straight，但在电话号码里必须说 sequential，说 straight 对方会愣住。第三，triple 和 three of a kind 都指三连号，但日常交易里 triple 更常用、更简短。第四，vanity number 这个词要小心：它的狭义是指用字母拼出单词的号码，广义才包含所有好记的号码；跟美国人聊个人靓号时，用 memorable number 或 pattern number 反而不容易产生误会。

常见问题

问：豹子号的英文到底怎么说？

答：说 repeater 或 repeating-digit number，这是英文号码市场通用的说法。千万不要直译成 leopard，美国人听不懂。

问：What is a repeater phone number?

答：A repeater phone number is one where the same digit repeats multiple times, for example 917-555-9999. It is the English term for what Chinese buyers call 豹子号.

问：顺子号的英文是 straight 吗？

答：不是。straight 是扑克牌里的顺子，电话号码里的顺子叫 sequential：递增是 sequential (ascending)，递减是 sequential (descending)。

问：美国人说的 vanity number 就是靓号吗？

答：大体对应，但 vanity number 狭义上指拼出单词的号码。聊个人用的三连号、四连号时，用 memorable number 或 pattern number 更准确，对方也更容易理解。

问：生日号 1225 这种美国人认可吗？

答：认可，birthday number 是通用说法。注意美国日期是月在前（12-25 即 12 月 25 日），跟国内习惯一致，不会产生误会。

问：三连号和四连号，英文里哪个更值钱？

答：一般来说 quad（四连号）比 triple（三连号）更稀缺，因为四位相同更难遇到。具体价格因号码而异，以联系确认为准。
